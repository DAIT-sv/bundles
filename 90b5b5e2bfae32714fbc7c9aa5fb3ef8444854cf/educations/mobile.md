# {eduIntro}

*En utbildning som ger en solid grund i programmering, databaser och webbutveckling innan specialisering på mobilutveckling.* Den omfattar UX för mobila enheter, cross-platform-utveckling med React Native och native-utveckling för iOS och Android. PWA och plattformsoberoende strategier ger verktyg för att välja rätt approach för varje projekt.

Utbildningen leder till roller som mobilutvecklare, apputvecklare, iOS-utvecklare eller Android-utvecklare – i appbolag, produktföretag, startups och organisationer som satsar på mobila lösningar.

# {specCourseTerm2}

**Introduktion till React Native**

Mobilutveckling med React-kunskaper. Grundläggande native-komponenter och navigation. Använda enhetsfunktioner som kamera och GPS. Bygga och testa en enkel app på riktig enhet.

**AI-aspekt:** Översätta webb-React-mönster till React Native, felsöka plattformsspecifika problem.

### Kursbeskrivningar termin 3

#### UX för mobila enheter (15 yhp)

Design för användare i rörelse. Kontext och användningsmiljö. Notiser och avbrott. Offline-först och synkronisering. Geolocation och platsbaserade tjänster. Gester och touch-interaktion bortom responsivitet.

**AI-aspekt:** Generera användarscenarior för mobila kontexter, analysera användningsmönster.

**Test-aspekt:** Testa appar i verkliga mobila situationer.

#### PWA och plattformsoberoende strategier (15 yhp)

Progressive Web Apps – installation, offline, push-notiser. Service workers och caching. När välja PWA, React Native eller native? Tekniska och affärsmässiga avvägningar. Framtidsspaning på mobila plattformar.

**AI-aspekt:** Generera service worker-konfiguration, analysera plattformsval.

**Test-aspekt:** Testa PWA-funktionalitet offline och på olika enheter.

#### React Native fördjupning (25 yhp)

Avancerad navigation och state management. Animationer och gestures. Native moduler och bryggor till plattformsspecifik kod. Prestanda och optimering. Publicering till App Store och Google Play.

**AI-aspekt:** Felsöka plattformsskillnader, generera animationer, optimera prestanda.

**Test-aspekt:** Enhetstester och integrationstester för React Native.

#### Native iOS med Swift (20 yhp)

Modern iOS-utveckling med Swift, med verktyg som SwiftUI. iOS-designmönster och Human Interface Guidelines. Integrationer med iOS-ekosystemet. App Store-publicering och riktlinjer. Testning och debugging i Xcode.

**AI-aspekt:** Generera Swift-komponenter, felsöka iOS-specifika problem.

**Test-aspekt:** Enhetstester och UI-tester för iOS.

#### Native Android med Kotlin (20 yhp)

Modern Android-utveckling med Kotlin, med verktyg som Jetpack Compose. Material Design och Android-konventioner. Integrationer med Android-ekosystemet. Google Play-publicering och riktlinjer. Testning och debugging i Android Studio.

**AI-aspekt:** Generera Kotlin-komponenter, felsöka Android-specifika problem.

**Test-aspekt:** Enhetstester och UI-tester för Android.
