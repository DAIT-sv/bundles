# {eduIntro}

*En utbildning som ger en solid grund i programmering, databaser och webbutveckling innan specialisering på C# och .NET-plattformen. Den omfattar robusta API:er med ASP.NET Core, Entity Framework mot databaser, och driftsättning i Azure. Kvalitetssäkring med BDD och kravanalys ger verktyg för att bygga rätt sak på rätt sätt.*

Utbildningen leder till roller som backend-utvecklare, .NET-utvecklare, systemutvecklare eller fullstack-utvecklare i Microsoft-ekosystemet – i både startup och enterprise.

# {specCourseTerm2}

**Introduktion till C# och .NET**

*C#-syntax med JavaScript som referenspunkt.* .NET-ekosystemet: dotnet CLI, NuGet, projektstruktur. Direkt till Minimal API – samma REST-tänk, nytt språk. Porta/återskapa ett enkelt Express-API i .NET.

**AI-aspekt:** Översätta Express-kod till .NET, förklara C#-syntax och .NET-koncept.

### Kursbeskrivningar termin 3

#### C# fördjupning (25 yhp)

*Fördjupning i C# med fokus på det som skiljer sig från JavaScript:* objektorientering med access modifiers, composition vs inheritance, interfaces, namespaces och projektstruktur. Typsystemet med generics och nullable types. LINQ för datamanipulation. Async/await med Tasks.

**AI-aspekt:** Översätta kodmönster från JavaScript till idiomatisk C#, förklara kompilatorfel.

**Test-aspekt:** Enhetstestning i C# med xUnit.

#### ASP.NET Core (20 yhp)

*Bygga webb-API:er i .NET.* Minimal API och Controllers, routing, middleware, dependency injection. Autentisering och auktorisering. Validering och felhantering.

**AI-aspekt:** Generera boilerplate, scaffolding av controllers, felsöka DI-konfiguration.

**Test-aspekt:** Integrationstester för API:er, testa autentisering/auktorisering.

#### Entity Framework Core (20 yhp)

ORM i .NET-världen. Code First, migrations, relationer. LINQ-queries mot databas. Prestanda och vanliga fallgropar. Jämförelse med raw SQL och när man väljer vad.

**AI-aspekt:** Generera modeller och migrations, optimera queries, felsöka relationer.

**Test-aspekt:** Testa databasoperationer med in-memory databas.

#### Kvalitetssäkring, kravanalys & BDD (15 yhp)

Kravanalys och acceptanskriterier som grund för kvalitetsarbete. Behavior-Driven Development (BDD) med Gherkin-syntax för att skriva tester som dokumentation. Test-Driven Development (TDD) som arbetssätt. Kodanalys, code review-processer och hantering av teknisk skuld.

**AI-aspekt:** Generera acceptanskriterier och BDD-scenarier från kravbeskrivningar.

**Test-aspekt:** Tillämpa BDD och TDD i projektarbete.

#### Azure-tjänster för .NET (15 yhp)

Driftsätta .NET-applikationer i Azure. App Service, Azure SQL, Blob Storage. CI/CD med GitHub Actions. Introduktion till Docker och containerisering.

**AI-aspekt:** Skriva deployment-scripts, felsöka Azure-konfiguration, generera CI/CD-pipelines.

**Test-aspekt:** Tester i deployment-pipeline, smoke tests efter deploy.
