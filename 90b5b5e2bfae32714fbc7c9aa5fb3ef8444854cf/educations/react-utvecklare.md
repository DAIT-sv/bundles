# {eduIntro}

*En utbildning som ger en solid grund i programmering, databaser och webbutveckling innan specialisering på React-ekosystemet.* Den omfattar avancerade webbapplikationer med Next.js, mobilappar med React Native, och typsäkra fullstack-lösningar. Driftsättning och DevOps ingår – hela vägen från kod till produktion.

Utbildningen leder till roller som frontend-utvecklare, fullstack-utvecklare, React-utvecklare eller mobilutvecklare – i produktbolag, byråer och startups som bygger moderna användargränssnitt.

# {specCourseTerm2}

**Introduktion till React Native**

Mobilutveckling med React-kunskaper. Expo som utvecklingsmiljö, grundläggande native-komponenter (View, Text, ScrollView), styling med StyleSheet. Navigation mellan skärmar. Använda enhetsfunktioner som kamera och GPS. Bygga och testa en enkel app på riktig enhet.

**AI-aspekt:** Översätta webb-React-mönster till React Native, felsöka plattformsspecifika problem.

### Kursbeskrivningar termin 3

#### Avancerad React (20 yhp)

Fördjupning i React: custom hooks, useReducer, Context API för komplex state. Performance-optimering med memo, useMemo, useCallback. Komponentmönster som compound components och render props. Error boundaries och Suspense.

**AI-aspekt:** Refaktorera komponenter för bättre prestanda, generera custom hooks.

**Test-aspekt:** Testa custom hooks, komponenttester för komplexa komponenter.

#### Next.js fullstack (25 yhp)

Fullstack-utveckling med Next.js. Server Components vs Client Components, Server Actions, Route Handlers. Caching-strategier och inkrementell regenerering. Middleware och edge functions. Autentiseringslösningar för Next.js. Databasintegration direkt i Next.js.

**AI-aspekt:** Generera API-routes, felsöka SSR/hydration-problem, optimera caching.

**Test-aspekt:** Testa Server Components, API-routes, integrationstester.

#### React Native (20 yhp)

Fördjupad mobilutveckling med React Native och Expo. Avancerad navigation, animationer, gestures. Offline-stöd och lokal lagring. Native moduler och plattformsspecifik kod. Publicering till App Store och Google Play.

**AI-aspekt:** Felsöka plattformsskillnader, generera animationer, optimera prestanda.

**Test-aspekt:** Testa native-komponenter, enhetstester för mobillogik.

#### Typsäker fullstack (15 yhp)

End-to-end typsäkerhet mellan frontend och backend. API-kontrakt och kodgenerering. Schema-validering med typinferens. Synkronisera typer mellan klient och server. Acceptanskriterier som grund för kontraktstestning.

**AI-aspekt:** Generera valideringsscheman, felsöka typfel över stacken, skapa API-kontrakt.

**Test-aspekt:** Kontraktstester mellan frontend och backend, testa mot acceptanskriterier.

#### Driftsättning & DevOps för React (15 yhp)

Publicera React/Next.js-applikationer i produktion. VPS-setup med grundläggande säkerhetshärdning, reverse proxy och webbserver. Processhantering för Node.js. Docker-grunder. CI/CD-pipelines för React-projekt. Molnplattformar vs egen server – när och varför.

**AI-aspekt:** Generera deployment-scripts, felsöka serverkonfiguration, skapa CI/CD-workflows.

**Test-aspekt:** E2E-tester i CI/CD-pipeline, smoke tests efter deploy.
